# Описания выпусков

Файлы `X.Y.Z.json` содержат пользовательские Release Notes на русском. Описания версий 1.0.0–1.5.0 восстановлены по соответствующим Git-тегам, изменениям между ними и документации в этих версиях. Даты взяты из тегов. Возможности, добавленные после тега, не включаются в его описание.

Для нового стабильного выпуска добавьте файл с номером версии, датой `YYYY-MM-DD`, кратким `summary` и массивами `features`, `improvements`, `fixes`. Пустые разделы оставляйте пустыми массивами. Проверка: `AVARI_VERSION=X.Y.Z node scripts/release-notes.mjs`.

Vite-плагин `scripts/release-assets.mjs` выдаёт `/release.json` и `/release-notes.json` в разработке и включает их в веб-сборку. Упаковка Go-сервера копирует те же файлы. История ограничена текущей версией сборки: `AVARI_VERSION`, а если она не задана — версией корневого `package.json`. Наличие файла описания более нового выпуска само по себе не меняет версию приложения и не добавляет его в историю старой установки.

Описания также используются при подготовке GitHub Release и манифеста обновления desktop. Здесь редактируются файлы репозитория; тексты уже опубликованных GitHub Releases автоматически не изменяются.
