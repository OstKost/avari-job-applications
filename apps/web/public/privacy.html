Политика конфиденциальности и обработки персональных данных Avari.Jobs

Настоящая Политика определяет порядок обработки и защиты персональных данных пользователей сервиса Avari.Jobs (доступного по адресу https://jobs.avari.dev и на персональных серверах пользователей) и браузерного расширения «Avari.Jobs — журнал откликов» в соответствии с требованиями Федерального закона РФ от 27.07.2006 № 152-ФЗ «О персональных данных» и международными стандартами приватности.

1. Правовые основания и принцип минимизации данных

Обработка персональных данных осуществляется на основании согласия пользователя, выражаемого при регистрации и использовании сервиса (п. 1 ч. 1 ст. 6 152-ФЗ), а также для исполнения соглашения об использовании функционала сервиса.

Мы строго придерживаемся принципа не собирать ничего лишнего (data minimization):

  • Сервис не требует предоставления паспортных данных, адресов регистрации, финансовых реквизитов или избыточных сведений.
  • Расширение и сервис не сканируют вкладки браузера, кроме страницы конкретной вакансии или отклика, открытой пользователем на поддерживаемых ресурсах.
  • Любые данные сохраняются в журнал только после явного подтверждения или прямого ввода пользователем.

2. Состав обрабатываемой информации

  • Сведения о вакансиях: название должности, наименование компании, город, уровень заработной платы, ссылки на открытую вакансию и описание.
  • Сведения об откликах: статусы откликов, даты и этапы найма, отображаемые на поддерживаемых сайтах (hh.ru, LinkedIn, Getmatch, Hirify, Geekjob, Habr Career, Huntflow).
  • Telegram (по выбору пользователя): при подключении бота сохраняются числовые идентификаторы пользователя и личного чата, имя, username и настройки сводок. При подтверждении регистрации бот показывает email аккаунта. Отправленные боту ссылки и тексты используются для выбранных действий; черновики диалогов действуют 24 часа. Вакансии и заметки сохраняются после подтверждения. Ответы и включённые сводки передаются через Telegram Bot API. Привязку можно отключить на сайте или в боте; она не входит в JSON-экспорт журнала.
  • Задачи, заметки, теги и черновики: данные, введённые пользователем для ведения журнала.
  • Вход: email и пароль учётной записи Avari.Jobs передаются выбранному серверу при входе.
  • Учётные данные расширения: токен сессии (API token), используемый исключительно для авторизации в журнале Avari.Jobs.

Расширение НЕ собирает: пароли к сайтам поиска работы, cookies сторонних сайтов, историю просмотров нерелевантных вкладок или личную переписку на сторонних сервисах.

2. Доступ к страницам (Content Scripts и Разрешения)

  • Расширение внедряет скрипты только на поддерживаемых страницах вакансий и откликов (hh.ru, LinkedIn, Getmatch, Hirify, Geekjob, Habr Career, Huntflow) с единственной целью — считать открытые пользователем данные вакансии для подготовки предложений; сохранение в журнал выполняется после подтверждения пользователем.
  • Скрипты не обращаются к закрытым API сайтов и считывают данные исключительно из DOM открытой пользователем вкладки.
  • Разрешение activeTab и scripting используется только для отображения интерфейса мини-окна при взаимодействии пользователя с расширением.

3. Хранение и передача данных

  • Локальное хранилище Chrome (chrome.storage): расширение локально сохраняет выбранный адрес сервера (по умолчанию https://jobs.avari.dev) и настройки подключения. Токен и одноразовый секрет входа хранятся только в доверенном контексте расширения: в ограниченном хранилище Chromium или хранилище origin расширения Firefox.
  • Передача данных: собранная информация о вакансии передаётся исключительно на сервер Avari.Jobs (на https://jobs.avari.dev или выбранный пользователем персональный сервер Avari).
  • Никаких сторонних трекеров: расширение не передаёт данные рекламным сетям, аналитическим брокерам или третьим лицам. Данные не продаются и не монетизируются.

4. Удаление и контроль данных

Пользователь имеет полный контроль над всеми сохранёнными записями:

  • Любую сохранённую вакансию, заметку или задачу можно в любой момент отредактировать или удалить непосредственно в веб-интерфейсе Avari.Jobs.
  • Для полного удаления учётной записи и всех связанных данных пользователь может обратиться к администратору сервера по указанному ниже адресу.

5. Веб-сервис, PWA и внешние сервисы

Веб-сервис хранит email, хеш пароля и данные журнала на выбранном сервере. Резервные копии могут сохранять удалённые записи до ротации копий.

Локальное хранилище PWA (IndexedDB и Service Worker): приложение может устанавливаться как Progressive Web App (PWA) на компьютер и мобильные устройства. Оболочка приложения кэшируется Service Worker для быстрого запуска.

  • Автономное чтение (Offline Read): доступно только при явном согласии пользователя (opt-in, по умолчанию выключено). При включении в локальной базе IndexedDB сохраняются последние загруженные списки вакансий, задач, календаря и открытые карточки откликов. Серверные сессионные токены никогда не сохраняются в постоянном кэше.
  • Локальные черновики (Drafts): формы вакансий, задач и заметок автоматически сохраняют вводимый текст локально в браузере с привязкой к аккаунту, предотвращая потерю данных при случайном закрытии страницы или обновлении приложения.
  • Очистка данных: при выходе из учётной записи (logout) или через настройки приложения локальный кэш журнала, детали и черновики полностью и безвозвратно удаляются из IndexedDB на данном устройстве. Очередь отложенных изменений (offline write queue) отсутствует: изменения отправляются на сервер только при наличии активного соединения.

Web Push уведомления:

  • Push-уведомления включаются только по явному действию пользователя (opt-in переключатель в настройках аккаунта). Запрос разрешения браузера (Notification permission) вызывается только при клике на включение.
  • При включении браузер генерирует уникальный адрес доставки (push endpoint) и криптографические ключи шифрования (p256dh, auth), которые сохраняются на сервере Avari.Jobs для адресации сообщений.
  • Только агрегированные данные: сообщения push формируются исключительно в виде обезличенных числовых сводок (количество запланированных задач и собеседований на день, прогресс выполнения цели 10 действий). Тела push-уведомлений никогда не содержат названий компаний, должностей, контактных лиц, заметок или конфиденциальных деталей.
  • Служба доставки push платформы (Apple Push Notification service для iOS/macOS, Google FCM для Android/Chrome, Mozilla Push Service для Firefox) передаёт зашифрованный полезный груз без доступа к открытому тексту.
  • Подписка отключается в любой момент в настройках Avari.Jobs или отзывом разрешения в браузере.

При включённой Google Analytics веб-сайт передаёт Google сведения о посещениях страниц, браузере и устройстве. Для аватара браузер обращается к Gravatar с SHA-256 хешем email; ссылка изменения аватара открывает Gravatar с email. Эти интеграции веб-сайта не используются для сбора содержимого вакансий, заметок или задач. Расширение не содержит Google Analytics.

Privacy Policy for Avari.Jobs Chrome Extension, PWA & Service

This Privacy Policy explains how the browser extension "Avari.Jobs — журнал откликов" (Avari.Jobs Application Tracker), the Progressive Web App (PWA), and the Avari.Jobs web platform (available at https://jobs.avari.dev and personal user instances) collect, handle, and store user data in full compliance with data protection laws and strict privacy principles.

1. Legal Basis & Data Minimization Principle

Personal data processing is based on explicit user consent provided when registering and utilizing the service, as well as the necessity to fulfill the application tracking service agreement.

We strictly adhere to the principle of collecting only what is strictly necessary:

  • We never request sensitive personal identity numbers, financial information, or unnecessary credentials.
  • Content scripts and the web application never inspect browser tabs outside of the specific job posting or negotiation page actively viewed and confirmed by the user.
  • Records are committed to your journal only following your explicit review and confirmation.

2. Data Collection & Handling

The extension collects only the information necessary to perform its core functionality — tracking and logging job applications:

  • Job details: job title, company name, location, compensation range, job posting URL, and description displayed on supported job boards (hh.ru, LinkedIn, Getmatch, Hirify, Geekjob, Habr Career, Huntflow).
  • Telegram (optional): connecting the bot stores your numeric Telegram user and private chat identifiers, display name, username, and digest preferences. Registration confirmation shows your account email in the bot. Links and text sent to the bot support your chosen actions; conversation drafts expire after 24 hours. Jobs and notes are saved after confirmation. Replies and enabled digests are sent through the Telegram Bot API. You can disconnect on the website or in the bot; the binding is excluded from journal JSON exports.
  • Application progress: application status and stage information shown on supported negotiation/application pages.
  • Authentication credentials: an API session token used exclusively to authenticate requests to the designated Avari.Jobs server.

The extension does not collect, read, or transmit login passwords of third-party job sites, third-party authentication cookies, general browsing history, or private chat messages.

2. Permissions and Content Scripts

  • storage: stores the designated Avari.Jobs server URL on the user's device. Authentication tokens and one-time login secrets remain in trusted extension contexts, using restricted Chromium storage or Firefox extension-origin storage.
  • activeTab and scripting: used solely to display the extension popup interface on the active tab upon user interaction.
  • Content scripts run only on supported job URLs to parse visible DOM elements to prepare suggestions; saving to the journal requires user confirmation.

3. Data Storage, Transmission & Sharing

  • All saved job details are transmitted solely to the user's configured Avari.Jobs instance (by default https://jobs.avari.dev, or a self-hosted server configured by the user).
  • No Sale of Personal Data: We do not sell, rent, or trade user data.
  • No Third-Party Advertising: The extension does not contain third-party ad networks, tracking SDKs, or data brokers.

4. User Rights and Data Deletion

Users maintain full control over their data:

  • Job entries, tasks, and notes can be modified or removed at any time through the web interface.
  • To request full account and data deletion, contact the administrator at the email below.

5. Web Service, PWA Offline Storage & Web Push

The web service stores your email, password hash and journal data on your selected server. Backups may retain deleted records until backup rotation. The extension also handles user-entered tasks, notes, tags and drafts; your Avari.Jobs email and password are sent to the selected server when signing in.

Progressive Web App (PWA) Offline Storage:

  • Offline Reading (Opt-In Only): Offline journal data caching in IndexedDB is strictly opt-in and disabled by default. When explicitly enabled by the user, the latest loaded vacancies, tasks, calendar entries, and viewed detail cards are cached locally for offline review. Session authentication tokens are never stored in this offline cache.
  • Local Drafts: Vacancy, task, and note input forms automatically persist unsaved text locally in IndexedDB scoped to the active account, protecting your work against accidental tab closures or app updates.
  • Cache Clearance: Signing out (logout) or manually clearing data via settings immediately purges all cached journal entries, details, and drafts from the device. There is no offline server mutation queue; all record modifications require an active server connection.

Web Push Notifications:

  • Push notifications are strictly opt-in on a per-device basis. Browser notification permissions are requested solely upon an explicit click to enable push in user settings.
  • When subscribed, your browser generates a push endpoint URL and encryption keys (p256dh, auth), which are stored on the Avari.Jobs server to route notifications.
  • Aggregate-Only Payloads: Notification messages contain only aggregate counts (e.g. number of planned tasks/interviews for today and progress towards the 10-actions weekday goal). They never contain company names, job titles, contacts, notes, or confidential text.
  • Platform push delivery services (Apple APNs for iOS/macOS, Google FCM for Android/Chrome, Mozilla WebPush for Firefox) transport encrypted payloads without access to plaintext content.
  • Push subscriptions can be revoked at any time via Avari.Jobs settings or by revoking site permissions in your browser.

When Google Analytics is enabled, the website sends Google page visit, browser and device information. To display an avatar, your browser contacts Gravatar with a SHA-256 hash of your email; the avatar editing link opens Gravatar with your email. These website integrations are not used to collect job, note or task contents. The extension does not contain Google Analytics.
