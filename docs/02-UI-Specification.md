# Спецификация интерфейсов MVP

Продуктовые требования описаны в `01-PRD.md`.

## Общие требования
- Тёмная тема по умолчанию и в приоритете; переключение на светлую тему с сохранением выбора. Палитра Arctic Depths: синие поверхности (#193546), светлый текст и акценты #0DB8D3 / #1B7FDC.
- Русский язык.
- Mobile-first: одна колонка, крупные зоны нажатия.
- Desktop: боковая навигация и более плотная компоновка.
- Статусы обозначаются текстом и цветом.
- Состояния экранов: загрузка, пустой список, ошибка, успех.
- Без чат-интерфейса. На входе и главной — спокойный векторный горный пейзаж по мотивам дизайн-референсов.

Навигация: `Главная` · `Календарь` · `Отклики` · `Предложения` · `Настройки`.
На мобильном — нижняя панель, на desktop — боковое меню.

## Экраны сайта
### Вход и регистрация
- Вкладки «Вход» и «Регистрация».
- Email, пароль; при регистрации — подтверждение пароля.
- Пояснение о ручном одобрении.
- Отдельные состояния ожидания и блокировки.
- Восстановление доступа — инструкция обратиться к администратору.

### Главная
- Приветствие, текущее время и дата в часовом поясе пользователя.
- Активные отклики, предстоящие интервью, офферы и ожидающие внимания задачи/предложения.
- План на сегодня с отметкой выполнения, последние обновлённые вакансии, распределение активных откликов по этапам.
- Быстрый доступ к откликам, календарю, предложениям и созданию задачи.

### Календарь
- Месячная сетка из 4–6 недель, начиная с понедельника; переход между месяцами и возврат к сегодняшнему дню.
- Задачи и интервью.
- Отдельный блок просроченных задач.
- Mobile: компактная сетка с индикаторами событий и повестка выбранного дня ниже.
- Desktop: сетка с названиями/временем задач, справа — повестка выбранного дня.
- Карточка: время, действие, компания, позиция, отметка выполнения.
- Кнопка «Добавить задачу».

### Отклики
- Поиск по компании и позиции.
- Фильтры по этапу, состоянию, приоритету и открытым задачам.
- Mobile: карточки. Desktop: таблица.
- Поля списка: компания, позиция, этап, дата отклика, ближайшее действие.
- Кнопка «Добавить».
- Сворачиваемые группы по этапу, состоянию, компании или приоритету.
- Сортировка по дате сохранения, компании или ближайшей задаче; страницы по 20 записей.
- Переключатель высоких/компактных строк; в высоких строках видны локация и формат работы.
- Отключаемая статистика справа: распределение этапов, доля вакансий на этапах HR и дальше, количество активных откликов без задач. Статистика учитывает всю отфильтрованную выборку, группировка — текущую страницу.
- Группировка, плотность строк и видимость статистики сохраняются локально отдельно для пользователя.

### Карточка вакансии
- Компания, позиция, ссылка на hh.ru.
- Этап и состояние процесса.
- Основные и custom-поля.
- Следующие действия.
- История событий.
- Кнопки редактирования, добавления заметки и задачи.
- Блок предложения изменения, если оно есть.

### Предложения
- Компания и позиция.
- Обнаруженное состояние.
- Сравнение текущих и предлагаемых значений.
- Время и источник.
- Кнопки «Применить», «Изменить», «Отклонить».

### Настройки
- Аккаунт и выход.
- Редактор пяти custom-полей.
- Инструкция установки расширения.
- Подключённые сессии расширения и отзыв доступа.

### Формы
Создание и редактирование вакансии, заметки, этапа и результата закрытия, задачи.
Mobile — полноэкранная форма, desktop — модальное окно.

## Расширение
Popup шириной около 380 px, прокрутка длинных форм, переход на сайт для полного управления.

| Экран | Содержание |
|---|---|
| Вход | Email, пароль, ссылка на регистрацию |
| Ожидание одобрения | Статус аккаунта, проверка статуса, выход |
| Неподдерживаемая страница | Пояснение, переход в журнал, ручное добавление |
| Новая вакансия | Извлечённые поля, выбор «Сохранена / Отклик отправлен», подтверждение |
| Существующая запись | Этап, ближайшая задача, изменение этапа, заметка, задача |
| Предложение изменения | Сравнение значений, применение, редактирование, отклонение |
| Несколько предложений | Список с индивидуальным подтверждением |
| Ошибка | Причина и действие: повторить, войти, добавить вручную |

Успешное сохранение показывается только после ответа backend.

## Уведомления
- Сайт: уведомление об успешном сохранении с цветным индикатором и кнопкой закрытия; автоматическое закрытие через пять секунд. Ошибки остаются рядом с операцией до исправления.
- Badge расширения — количество новых предложений.
- Popup — детали и действия.
- Системные уведомления браузера — опционально.

Тексты:
- «Можно добавить вакансию в журнал».
- «Обнаружено изменение по сохранённой вакансии».
- «Найдено 3 предложения обновления».

Правила:
- Не повторять уведомление об одном наблюдении.
- Не уведомлять при каждом открытии сохранённой вакансии.
- Не повторять отклонённое предложение до нового изменения.
- Системные уведомления по умолчанию не раскрывают компанию и результат.
- Нажатие на уведомление открывает предложения на сайте.

## TUI администрирования
Разделы: заявки, пользователи, административный журнал, резервные копии.

Интерфейс:
- Таблицы, поиск и фильтры.
- Навигация клавиатурой.
- Карточка выбранного пользователя.
- Цветовые индикаторы состояний.
- Строка подсказок горячих клавиш.
- Диалоги подтверждения изменяющих операций.
- Понятные результаты и ошибки.

Операции и ограничения доступа описаны в PRD.

## Задание агенту генерации
Подготовить:
- Мобильные и desktop-экраны сайта.
- Все состояния popup расширения.
- TUI администрирования.
- Общие компоненты карточек, статусов, истории, задач и сравнения изменений.
- Переходы и сценарии подтверждения.
- Mock-данные и mock-парсер.

Дизайн веб-приложения обновлён по референсам в `docs/UI`. Авторизация, backend и парсеры подключены к реальным данным. Новые группировки и настройки представления работают поверх существующей модели вакансий.

Группы откликов доступны над таблицей в виде переключателей с иконками папок. Выбор группы ограничивает список и статистику всеми её записями после текущих фильтров; пагинация применяется внутри выбранной группы. Сайт и расширение используют общую синюю палитру Arctic Depths; тёмная тема включена по умолчанию.
