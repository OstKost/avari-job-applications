# Avari.Jobs — проморолик для Chrome Web Store

Файл: [avari-jobs-promo-ru.mp4](avari-jobs-promo-ru.mp4).
40 секунд, 1920×1080, 24 кадра/с, H.264 / AAC, 16:9.
Русские титры, без диктора, с негромкой синтезированной фоновой музыкой.
Музыка создана локально скриптом: сторонние записи не используются.
Интерфейс показан на демонстрационных данных из E2E-снимков проекта.
Это анимированный обзор со скриншотами, а не непрерывная запись действий пользователя.

## Название для YouTube

Avari.Jobs — вакансии, отклики и интервью в одном журнале

## Описание для YouTube

Avari.Jobs помогает держать поиск работы в порядке: сохраняйте вакансии из браузера, отслеживайте этапы отбора, добавляйте заметки и планируйте интервью.

Расширение поддерживает карточки вакансий на hh.ru, LinkedIn, Getmatch и Hirify. Компания, позиция и другие доступные сведения подставляются из открытой страницы. Недостающие поля можно дополнить вручную.

Установить расширение:
https://chromewebstore.google.com/detail/kcjlbhiglbeipdanlkfahodkfedplfnm

Подробнее и начало работы:
https://jobs.avari.dev/extension

Для работы нужен аккаунт Avari.Jobs. Доступно подключение к собственному серверу.

В ролике показан настоящий интерфейс с демонстрационными данными.

## Публикация

1. Загрузить MP4 на нужный YouTube-канал и вставить название и описание выше.
2. При необходимости выбрать подготовленную обложку и добавить файл русских субтитров. Основные титры уже встроены в видео.
3. Выбрать доступ «Открытый» или «По ссылке», проверить, что встраивание разрешено, и дождаться обработки Full HD.
4. Вставить полученную ссылку вида `https://www.youtube.com/watch?v=…` в поле «Глобальный проморолик» в Chrome Web Store.

Chrome Web Store принимает ссылку на YouTube: [официальная документация](https://developer.chrome.com/docs/webstore/cws-dashboard-listing#graphic-assets).
Ролик загружен 16 октября 2026 года на канал Avari Development (@avari.development), доступ «По ссылке», встраивание разрешено. Проверка YouTube завершена без нарушений.

Ссылка для поля «Глобальный проморолик»: https://www.youtube.com/watch?v=stsT5sQduUw

Канал: https://www.youtube.com/channel/UC8RD0yMgyvYU34Jez6W5fIA

Собственная обложка не загружена: YouTube требует подтверждения номера телефона. Используется автоматически выбранный кадр. Титры встроены в видео; дополнительный SRT не загружен. Ссылка добавлена в поле «Глобальный проморолик» карточки Chrome Web Store. 17 октября 2026 года версия расширения 1.2.0 отправлена на проверку вместе с этой ссылкой. Подтверждён статус «Ожидает рассмотрения». Автоматическая публикация после проверки отключена; после одобрения требуется ручная публикация.

## Повторный экспорт

Нужны Python 3, Pillow и FFmpeg с H.264/AAC. Вместо системного FFmpeg можно установить Python-пакет `imageio-ffmpeg`.

```sh
python3 scripts/promo-video.py --preview
python3 scripts/promo-video.py
```

Исходные кропы интерфейса сохранены в `video-source/`. Логотип берётся из `apps/extension/public/brand/icon-128.png`. Скрипт поддерживает `FFMPEG` и `AVARI_PROMO_FONT_DIR` для явного выбора бинарника и папки с Arial. На Linux используется DejaVu Sans, если Arial недоступен.
